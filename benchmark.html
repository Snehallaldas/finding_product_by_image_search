{
  "version": 1,
  "catalog": [
    { "id": "shoe-001", "image": "catalog/shoe-001-front.jpg", "category": "shoes" },
    { "id": "shoe-002", "image": "catalog/shoe-002-side.jpg", "category": "shoes" }
  ],
  "queries": [
    { "id": "query-001", "image": "queries/shoe-001-outdoor.jpg", "relevant_product_ids": ["shoe-001"], "category": "shoes" }
  ]
}

Each catalog image needs a unique product ID. Add one or more relevant IDs for every query; queries can have multiple correct products. Category is optional and can be shoes, sandals, or all.

Detailed mode downloads the OWL-ViT detector (about 127 MB) on first use. Both modes analyze images serially; larger test sets take longer. Keep this tab open.
